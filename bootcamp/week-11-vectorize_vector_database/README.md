# Semana 11 — Vectorize: Vector Database en el Edge

> **Etapa 2 — AI en el Edge** · Bootcamp Cloudflare De Cero a Héroe

---

## 🎯 Objetivos

- Crear y configurar índices Vectorize con `wrangler` y `wrangler.jsonc`
- Insertar y actualizar vectores con metadata mediante el binding `VectorizeIndex`
- Ejecutar búsquedas de vecinos más cercanos (ANN) con filtros de metadata
- Combinar Workers AI (embeddings) con Vectorize para búsqueda semántica
